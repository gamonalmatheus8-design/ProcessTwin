# ProcessTwin AI

Plataforma inteligente para reconstrução, análise e simulação de processos empresariais.

## Objetivo

O ProcessTwin AI transforma logs de eventos em um gêmeo digital do processo real, identifica gargalos e permite testar cenários "e se?" antes de aplicar mudanças na operação.

## Núcleo da V1

- Importação de dados de processo em CSV
- Reconstrução visual do fluxo
- Indicadores de tempo, espera e gargalos
- Simulation Lab para cenários "e se?"
- Comparação entre cenário atual e simulado
- Base preparada para análises inteligentes

## Stack planejada

- Next.js + TypeScript
- Supabase / PostgreSQL
- Python para análise e simulação quando necessário
- Deploy web na Vercel

## Fluxo principal

Dados -> Process Mining -> Mapa do Processo -> Gargalos -> Simulação -> Comparação
